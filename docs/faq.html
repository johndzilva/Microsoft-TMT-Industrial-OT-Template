Troubleshooting and FAQ#

TMT says the model is corrupted#

Usually the message is "Line element coordinates are corrupted" or "Border … will be corrected". It means an element or line lies outside TMT's drawing area. Keep the drawing within about 1800 × 1100 pixels. Models made with build_model.py are kept inside it automatically.

TMT crashes when I open a second model#

TMT 2016 can crash ("Unhandled exception") when you open a model while another model's threat list is still showing. Close the first model with File > Close Model before opening the next.

The same threat appears on many flows#

Set Threats on this Flow = All on one flow into the component and Without component threats on the others, or run check_model.py. For parallel flows over the same channel, set Path threats only on all but one. See How threats are generated.

A threat cannot apply to my system#

First check whether a property removes it. The Properties page lists which value removes which threat. Answering the property makes the threat disappear for good. If no property fits, mark the threat Not Applicable with a justification.

There are no threats on the zones themselves#

TMT only generates threats for data flows. Zone properties record the risk assessment inputs. Threats that depend on the zone use the properties of the assets and flows inside it.

Can I use Microsoft's own threats too?#

These templates contain only OT threats. Microsoft's stencils are included so that the IT parts of a system can be drawn. For Microsoft's web and cloud threats, model those parts with Microsoft's templates.

The templates are in English. Can I use them for Korean projects?#

Yes. The stencils, properties and threat texts appear in TMT in English, which keeps the threat IDs and standard references consistent across teams. You can write names, justifications and review fields in Korean, and TMT saves them as entered.

I have models made with version 1.x#

Apply the 2.0 template with File > Apply Template, then run check_model.py. Threat IDs are unchanged, so existing reviews stay valid. See Versions and licence and MIGRATION.md.

Do I need CVSS?#

No. See Reviewing threats.
