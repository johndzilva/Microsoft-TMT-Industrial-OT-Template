Examples#

Two complete models are in the examples folder. Open them with Open A Model and switch to Analysis View.

Industrial edge gateway (product template)#

examples/Industrial Edge Gateway - Product Threat Model.tm7 models an industrial IoT edge gateway as an IEC 62443-4-2 component. It generates 138 threats.

Where Elements
Inside the product boundary Southbound Protocol Service, Container Runtime and Apps (behind a Container isolation privilege boundary), Cloud Connector, Web Management UI, Gateway Firmware and OS, Firmware Update Agent, Gateway Configuration, Local Audit Log, Key Store in TPM, Firmware Image A and B
Vendor and cloud, beyond an Internet boundary Cloud IoT Platform, Vendor Update Server
Plant side Machine PLCs and Drives, Maintenance Engineer, Vendor Service Technician, USB Stick for Configuration Import, Site Time Server, Gateway Vendor Development and Build

What it shows:

  • Machines are polled over Modbus TCP without security. Telemetry and commands use MQTT over TLS. Firmware is downloaded over HTTPS, verified and written to an A/B image. Keys are in a TPM.
  • The hardware platform is physically exposed, with debug ports, USB and wireless. Its device threats (secure boot, debug interfaces, key extraction) appear once, on its anchor flow. The software functions run on it, so host threats are not repeated on them.
  • The supplier's build pipeline flow carries the supply chain threats (OT-T28, OT-S12). The container boundary carries the isolation threat (OT-E23). The read-only key store gets its data-at-rest threats on its outgoing flow (OT-I11R).

Natural gas pipeline (plant template)#

examples/Gas Pipeline - Site Risk Assessment.tm7 assesses a gas transmission pipeline. It generates 114 threats.

Zone (consequence, SL-T / SL-A) Elements
Enterprise IT, Level 4 (minor) Corporate IT and Gas Scheduling
Control Centre DMZ, Level 3.5 (moderate) Remote Access Gateway, DMZ Historian
Pipeline Control Centre, Levels 2 and 3 (major, SL-T 2 / SL-A 2) Pipeline SCADA Server, Pipeline Controller HMI, Engineering Workstation, Leak Detection System (end of life), Pipeline Historian
Compressor Station, Levels 1 and 0 (catastrophic, unattended, SL-T 2 / SL-A 1) Station Cellular Router, Station RTU, Compressor Unit Control PLC, Compressor Unit and Station Piping
Station Safety Zone, ESD (catastrophic, unattended, SL-T 3 / SL-A 1) Station ESD System
Block Valve Site, Level 1 (major, unattended, SL-T 2 / SL-A 0) Valve Site RTU, Mainline Valve Actuator
Outside the zones Compressor OEM Remote Support (always-on VPN), Pipeline Controller, Field Technician Laptop

What the assessment brings out:

  • Remote sites over public networks: station telemetry runs DNP3 without security over cellular, and the valve site uses licensed radio.
  • Business dependency: gas nominations go from corporate scheduling straight into SCADA without a conduit device. This is the IT-to-OT dependency behind the 2021 Colonial Pipeline shutdown (PL-E01, PL-E02).
  • Safety: the compressor PLC can reset the ESD remotely, so the safety system is reachable from the control side (PL-E10, PL-T07). The hard-wired trip inputs carry the field wiring threat (PL-T11).
  • Site practice: shared accounts, unhardened RTUs, no monitoring at remote sites, an always-on OEM VPN (PL-E05), and a field laptop used for PLC programming (PL-T09).
