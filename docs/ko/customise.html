사용자 정의와 재빌드#

템플릿은 Python으로 생성되므로, 변경 사항을 검토하고 반복하고 병합하기 쉽습니다.

소스 파일#

파일 내용
elements.py 스텐실과 속성: Stencils 창과 Element Properties 창에 나타나는 것
threats.py 제품 위협: 텍스트, 규칙, 참조, 계열
threats_plant.py 플랜트 위협
icons.py 스텐실 아이콘 (Tabler Icons, MIT)
build.py .tb7을 만듭니다. 플랜트 템플릿은 --plant
validate.py TMT가 강제하는 규칙에 맞는지 .tb7을 점검합니다
readme_properties.py 속성 도움말 텍스트. 이 사이트의 표에 사용됩니다
site/build_site.py 이 웹사이트를 docs/에 만듭니다

재빌드#

필요 조건: Python 3, Pillow, 아이콘 렌더링용 Playwright와 Chromium. 그리고 TMT 설치 폴더의 default.tb7을 source/에 복사해야 합니다. Microsoft 기본 스텐실이 이 파일에서 옵니다.

cd source
python build.py "../OT Product and System Threat Template (IEC 62443).tb7"
python build.py --plant "../OT Plant and Site Risk Assessment Template (IEC 62443).tb7"
python validate.py "../OT Product and System Threat Template (IEC 62443).tb7" default.tb7
python validate.py "../OT Plant and Site Risk Assessment Template (IEC 62443).tb7" default.tb7
python release_check.py "../OT Product and System Threat Template (IEC 62443).tb7" "../OT Plant and Site Risk Assessment Template (IEC 62443).tb7"
cd ../site
python build_site.py

스텐실 추가#

elements.py의 STANDARD에 추가하고 icons.py에서 아이콘을 지정합니다. 두 템플릿 모두에 나타납니다. 적용될 수 없거나 스텐실이 암시하는 속성이 있으면 고정값을 STATIC에 추가합니다.

위협 추가#

  1. threats.py 또는 threats_plant.py에 add(...) 항목을 추가합니다. 제목, 설명, 대응책, 포함·제외 규칙, ATT&CK, IEC 참조, FR, SL을 넣습니다.
  2. FAM에서 계열을 지정합니다. 계열 2, 3, 4, 8은 Auto일 때 노출된 흐름에만 표시할지도 정합니다(GATED).
  3. 다시 빌드하고 release_check.py를 실행합니다. 계열이 없는 위협이 있으면 실패합니다.

TMT가 강제하는 규칙

validate.py가 다음을 점검합니다.

  • 속성 표시 이름은 고유해야 합니다.
  • 스텐실 이름에는 영문자, 숫자, 공백, 밑줄, 마침표만 씁니다.
  • 규칙에 쓰는 속성 값은 하이픈이나 쉼표 없는 평범한 단어여야 합니다.
  • 영역 스텐실은 BorderBoundary 표현을 유지합니다.

ID는 바꾸지 마세요

다른 사람들이 요구사항과 위험 등록부에서 위협 ID를 참조합니다. 새 ID를 추가하고, 번호를 다시 매기지 마세요.

이 사이트 게시하기#

사이트는 docs/에 있는 일반 HTML이며, GitHub에서 별도 빌드가 필요 없습니다. 저장소의 Settings > Pages에서 Deploy from a branch, 브랜치 main, 폴더 /docs를 선택하세요. 상단 바에 GitHub 링크를 표시하려면 build_site.py 실행 전에 OTTM_REPO=https://github.com/<사용자>/<저장소>를 설정합니다.
