문제 해결 및 FAQ#

TMT가 모델이 손상되었다고 표시합니다#

보통 "Line element coordinates are corrupted"나 "Border … will be corrected" 메시지가 나옵니다. 요소나 선이 TMT 그리기 영역 밖에 있다는 뜻입니다. 다이어그램을 약 1800 × 1100 픽셀 안에 그리세요.

두 번째 모델을 열면 TMT가 종료됩니다#

TMT 2016은 한 모델의 위협 목록이 표시된 상태에서 다른 모델을 열면 비정상 종료("Unhandled exception")될 수 있습니다. 다음 모델을 열기 전에 File > Close Model로 현재 모델을 닫으세요.

같은 위협이 여러 흐름에 나타납니다#

구성요소로 들어오는 흐름 하나에 Threats on this Flow = All, 나머지에 Without component threats를 설정하세요. 같은 채널의 병렬 흐름은 하나만 남기고 나머지를 Path threats only로 설정합니다. 위협이 생성되는 방식 참조.

우리 시스템에 적용될 수 없는 위협이 있습니다#

먼저 그 위협을 없애는 속성이 있는지 확인하세요. 속성 페이지에 어떤 값이 어떤 위협을 제거하는지 나와 있습니다. 속성에 답하면 위협이 완전히 사라집니다. 해당하는 속성이 없으면 사유와 함께 Not Applicable로 표시하세요.

영역 자체에는 위협이 없습니다#

TMT는 데이터 흐름에만 위협을 생성합니다. 영역 속성은 위험 평가 입력을 기록하는 용도입니다. 영역에 따라 달라지는 위협은 영역 안 자산과 흐름의 속성을 사용합니다.

Microsoft 자체 위협도 쓸 수 있나요?#

이 템플릿에는 OT 위협만 있습니다. Microsoft 스텐실은 시스템의 IT 부분을 그릴 수 있도록 포함했습니다. Microsoft의 웹·클라우드 위협이 필요하면 해당 부분을 Microsoft 템플릿으로 모델링하세요.

템플릿이 영어인데 한국 프로젝트에 써도 되나요?#

네. 스텐실, 속성, 위협 텍스트는 TMT에 영어로 표시되므로 팀 간에 위협 ID와 표준 참조를 일관되게 쓸 수 있습니다. 요소 이름, 사유, 검토 필드는 한국어로 입력해도 되며, TMT는 입력한 그대로 저장합니다.

버전 1.x로 만든 모델이 있습니다#

File > Apply Template로 2.0 템플릿을 적용한 뒤 앵커 흐름을 설정하세요. 위협 ID는 그대로이므로 기존 검토 결과도 유효합니다. 버전 및 라이선스를 참고하세요.

CVSS가 필요한가요?#

필요하지 않습니다. 위협 검토 참조.
