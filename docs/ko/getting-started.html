설치 및 빠른 시작#

다운로드부터 첫 OT 위협 목록까지 약 5분이면 됩니다.

준비물#

  • Windows와 무료 Microsoft Threat Modeling Tool. 템플릿은 TMT 2016에서 검증했습니다.
  • 이 저장소의 템플릿 파일 두 개.

빠른 시작#

  1. TMT 설치Microsoft Threat Modeling Tool을 내려받아 설치합니다.
  2. 템플릿 받기이 저장소를 내려받습니다(초록색 Code 버튼 > Download ZIP, 또는 git clone).
  3. 템플릿 선택TMT를 열고 Template For New Models 아래의 Browse를 눌러 OT Product and System Threat Template (IEC 62443).tb7 또는 OT Plant and Site Risk Assessment Template (IEC 62443).tb7을 선택합니다.
  4. 모델 만들기Create A Model을 누르면 오른쪽 Stencils 창에 OT 스텐실이 나타납니다.
  5. 그리고 답하기스텐실을 끌어다 놓고, 프로토콜 흐름으로 연결하고, 영역을 그려 감싼 다음, 각 요소와 흐름의 속성에 답합니다.
  6. 위협 생성View > Analysis View를 선택하면 TMT가 모든 흐름의 위협을 생성합니다.
  7. 검토와 보고서위협을 하나씩 검토한 뒤 Reports > Create Full Report로 보고서를 만듭니다.

먼저 동작을 확인해 보세요

예제 중 하나를 Open A Model로 열고 Analysis View로 전환해 보세요. 엣지 게이트웨이는 위협 138개, 가스 배관은 114개를 생성합니다.
