속성#

속성은 TMT의 Element Properties 창에 있는 질문입니다. 답에 따라 나타나는 위협이 정해집니다.

속성의 동작 방식#

  • 모든 속성은 Unknown에서 시작하며, 이 상태에서는 위협이 남습니다. 적용될 수 없는 위협은 No로 답해 없앱니다.
  • 스텐실에 적용될 수 없거나 스텐실이 이미 답을 아는 속성은 고정되어 Predefined Static Attributes 아래에 회색으로 표시됩니다. 소프트웨어에는 디버그 포트, USB, 무선, 물리적 노출이 없습니다. 안전 제어기는 항상 안전 관련입니다. 무선 링크의 매체는 항상 Wireless입니다. HTTPS와 IPsec은 항상 무결성과 암호화를 제공합니다.
  • (record only) 표시가 있는 속성과 영역 속성은 모델을 기록할 뿐 위협을 바꾸지 않습니다. TMT 규칙은 흐름의 양 끝과 흐름 자체만 볼 수 있고, 주변 영역은 볼 수 없기 때문입니다.
  • Microsoft 기본 스텐실(OS Process, SQL Database, HTTPS 등)도 그릴 수 있으며, OT 속성만 가집니다.

TMT 화면은 영어입니다

속성 이름과 값(Unknown, Yes, No 등)은 TMT에 영어로 표시되므로 아래 표에서도 영어 그대로 적고, 의미는 한국어로 설명했습니다.
