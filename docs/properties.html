Properties#

Properties are the questions in TMT's Element Properties pane. The answers decide which threats appear.

How properties work#

  • Everything starts at Unknown, which keeps the threat. Answer No to remove threats that cannot apply.
  • Properties that cannot apply to a stencil, or that the stencil already answers, are fixed and shown greyed out under Predefined Static Attributes. Software has no debug ports, USB, radio or physical exposure. A safety controller is always safety-related. A wireless link always has the Wireless medium. HTTPS and IPsec always have integrity and encryption.
  • Properties marked (record only), and the zone properties, document the model but do not change the threats. TMT rules can only see the two ends of a flow and the flow itself, not the zone around them.
  • Microsoft's built-in stencils (OS Process, SQL Database, HTTPS and so on) can be drawn too, with the OT properties only.
