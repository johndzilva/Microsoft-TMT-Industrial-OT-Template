OT threat modeling with Microsoft TMT#

IEC 62443 · MITRE ATT&CK for ICS · Free and open

Free templates for the Microsoft Threat Modeling Tool that turn a drawing of your PLCs, SCADA servers, gateways, protocols and security zones into a list of OT-specific threats. Each threat is mapped to IEC 62443 requirements and ATT&CK for ICS techniques and is ready to score.

Get started → New to threat modeling? Browse the threats

Two templates#

OT Product and SystemFor product suppliers and system integrators. What must this PLC, gateway, SCADA package or control system resist, and which requirements does it need? IEC 62443-4-2, 3-3 and 4-1. 110 threats. OT Plant and Site Risk AssessmentFor asset owners and plant OT security teams. What can go wrong at this site, how bad would it be, and are the existing countermeasures enough? IEC 62443-3-2, 2-1, 2-4 and IEC 61511. 43 threats.

Both templates share the same 82 OT stencils, alongside Microsoft's 52 built-in ones, so a diagram drawn with one template opens with the other.

What's inside#

82OT stencils: devices, software, people, data stores, 23 industrial protocols, zones and conduits
110product and system threats, IDs OT-xxx
43plant and site threats, IDs PL-xxx
8threat families, so each threat appears once, where it belongs
Part What it is
Templates (.tb7) The files you load into TMT. Each holds stencils, properties, threat rules and threat fields.
Stencils OT building blocks, grouped by IEC 62443-4-2 component type: embedded (EDR), host (HDR), network (NDR) and software (SAR). See Stencils.
Threat library Each threat has a stable ID, STRIDE category, description, mitigations, IEC 62443 references, ATT&CK for ICS techniques and the lowest security level where it applies. See the Threat catalogue.
Properties Questions on each element and flow ("Has a web interface?", "Protocol security in use?"). The answers decide which threats appear. See Properties.
Examples An industrial edge gateway and a natural gas pipeline, ready to open. See Examples.
Tools Python tools that build a model from a JSON description, check a model and rebuild the templates. See Command-line tools.
