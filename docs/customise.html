Customise and rebuild#

The templates are generated from Python, so changes are reviewable, repeatable and easy to merge.

Source files#

File Holds
elements.py Stencils and properties: what appears in the Stencils and Element Properties panes
threats.py The product threats: text, rules, references, family
threats_plant.py The plant threats
icons.py Stencil icons (Tabler Icons, MIT)
build.py Writes a .tb7; use --plant for the plant template
validate.py Checks a .tb7 against the rules TMT enforces
readme_properties.py Property help text, used for the tables on this site
site/build_site.py Builds this website into docs/

Rebuild#

Requirements: Python 3, Pillow, and Playwright with Chromium to render the icons. You also need TMT's own default.tb7, copied from the TMT install folder into source/; it supplies Microsoft's built-in stencils.

cd source
python build.py "../OT Product and System Threat Template (IEC 62443).tb7"
python build.py --plant "../OT Plant and Site Risk Assessment Template (IEC 62443).tb7"
python validate.py "../OT Product and System Threat Template (IEC 62443).tb7" default.tb7
python validate.py "../OT Plant and Site Risk Assessment Template (IEC 62443).tb7" default.tb7
python release_check.py "../OT Product and System Threat Template (IEC 62443).tb7" "../OT Plant and Site Risk Assessment Template (IEC 62443).tb7"
cd ../site
python build_site.py

Add a stencil#

Add it to STANDARD in elements.py and give it an icon in icons.py. It appears in both templates. If a property cannot apply to it or is implied by it, add the fixed value to STATIC.

Add a threat#

  1. Add an add(...) entry in threats.py or threats_plant.py, with the title, description, mitigation, the include and exclude rules, ATT&CK, IEC references, FR and SL.
  2. Give it a family in FAM. For families 2, 3, 4 and 8, also decide whether Auto shows it only on exposed flows (GATED).
  3. Rebuild and run release_check.py. It fails if a threat has no family.

Rules TMT enforces

validate.py checks these:

  • Property display names are unique.
  • Stencil names use only letters, numbers, spaces, underscores and periods.
  • Property values used in rules are plain words, without hyphens or commas.
  • Zone stencils keep the BorderBoundary representation.

Keep IDs stable

Others reference threat IDs from requirements and risk registers. Add new IDs; never renumber.

Publish this site#

The site is plain HTML in docs/, with no build step on GitHub. In your repository, open Settings > Pages, choose Deploy from a branch, branch main, folder /docs. To show a GitHub link in the top bar, set OTTM_REPO=https://github.com/<you>/<repo> before running build_site.py.
