Install and quick start#

From download to your first list of OT threats in about five minutes.

Requirements#

  • Windows with the Microsoft Threat Modeling Tool, which is free. The templates are tested with TMT 2016.
  • The two template files from this repository.

Quick start#

  1. Install TMTDownload and install the Microsoft Threat Modeling Tool.
  2. Get the templatesDownload this repository (green Code button > Download ZIP, or git clone).
  3. Choose the templateOpen TMT. Under Template For New Models, click Browse and choose OT Product and System Threat Template (IEC 62443).tb7 or OT Plant and Site Risk Assessment Template (IEC 62443).tb7.
  4. Create a modelClick Create A Model. The OT stencils appear in the Stencils pane on the right.
  5. Draw and answerDrag in stencils, connect them with protocol flows, draw zones around them, and answer the properties of each element and flow.
  6. GenerateChoose View > Analysis View. TMT generates the threats for every flow.
  7. Review and reportReview each threat, then use Reports > Create Full Report.

See it working first

Open one of the examples with Open A Model and switch to Analysis View. The edge gateway generates 138 threats and the gas pipeline 114.
