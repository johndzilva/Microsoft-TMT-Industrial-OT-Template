Versions and licence#

2.0#

  • Each threat appears once, where it belongs. There are 8 threat families, each with one anchor (see How threats are generated). The gateway example went from 230 to 138 threats; what disappeared were repeats and threats that could not apply.
  • Fewer properties. The 31 Microsoft core properties that drove no OT threat were removed. A component now has 16 properties instead of 25, a flow 7 instead of 21, and a data store 3 instead of 12. Three flow switches were merged into one: Threats on this Flow. Record-only properties are labelled.
  • Property applicability. Stencils fix the properties that cannot apply (no debug ports, USB, radio or physical exposure on software) or that they imply. The hardware questions gained Not applicable.
  • New properties. Assessment Scope (In scope, Supplier evidence, Out of scope), Runs on a Host Shown in the Model, and Show Data Store Threats for Source Store.
  • Non-network media. Hardwired signal and Local operator input. Channel threats skip them, and wiring threats cover them.
  • Overlaps removed. Generic sniffing, replay and DoS threats step aside where a specific threat covers the same attack.
  • New threats. OT-E23 isolation bypass, OT-T30 and PL-T11 wiring tampering, and data-at-rest threats for read-only stores (IDs ending in R). New stencils: Product Supplier and Development Environment, and Software Supply and Build Pipeline.
  • Tools. check_model.py and release_check.py were added. build_model.py now sets the anchors.

Upgrading from 1.x#

  1. Export your 1.x threat list or report first. The review decisions of repeats that 2.0 drops are not carried over.
  2. Open the model and use File > Apply Template with the 2.0 template. New properties start at their defaults; Threats on this Flow = Auto gives the 1.x behaviour.
  3. Run check_model.py and set the anchors it lists.
  4. Values of the removed Microsoft properties are dropped. Copy anything you recorded there into the element's notes first. Generate Threats = No becomes Threats on this Flow = None.

Threat IDs are unchanged. Full details are in MIGRATION.md.

Earlier versions#

  • 1.3: the plant and site template, build_model.py, and the edge gateway and gas pipeline examples.
  • 1.2: 10 threats added so every ATT&CK for ICS tactic is covered.
