Stencils#

82 OT stencils, shared by both templates, plus Microsoft's 52 built-in stencils.

  • Component stencils are prefixed with their IEC 62443-4-2 type: EDR embedded device, HDR host device, NDR network device, SAR software application.
  • Icon colour shows the type: blue embedded device, teal host device, orange network device, green software application, slate interactor, purple data store, brown protocol, red boundary.

Embedded devices (EDR) · 7

Stencil (as shown in TMT)What it represents
EDR PLC or Process ControllerProgrammable logic controller or DCS controller executing control logic (IEC 61131-3). Typical interfaces: engineering protocol, fieldbus, I/O, web UI.
EDR Safety Controller SIS SIL ratedSafety instrumented system logic solver (IEC 61508 / IEC 61511). Treat any compromise as a potential loss-of-safety event.
EDR RTU or Remote Field ControllerRemote terminal unit or remote controller, often at unattended sites, using DNP3, IEC 60870-5-104 or Modbus over WAN, radio or cellular.
EDR IED or Protection RelayIntelligent electronic device or protection relay (IEC 61850, DNP3). Protection functions are safety- and grid-critical.
EDR Smart Field Device sensor actuator drive analyzerLevel 0/1 device such as a transmitter, positioner, VFD, servo drive or analyzer with digital communication (HART, PROFINET, IO-Link, EtherNet/IP).
EDR IIoT Device or Edge SensorConnected sensor or device that sends telemetry to an edge gateway or cloud (MQTT, OPC UA, HTTPS).
EDR Safety IO ModuleSafety-rated I/O module communicating over a safety protocol (PROFIsafe, CIP Safety, FSoE) on a black channel.

Host devices (HDR) · 3

Stencil (as shown in TMT)What it represents
HDR Industrial PC or Panel PCIndustrial PC or panel PC hosting HMI, soft-PLC or gateway software, typically Windows or Linux.
HDR OT Server for SCADA DCS or HistorianServer platform (physical or virtual) hosting OT applications in Level 2/3.
HDR Engineering WorkstationWorkstation or laptop used for engineering, configuration and maintenance. Often has the highest privileges over controllers.

Network devices (NDR) · 6

Stencil (as shown in TMT)What it represents
NDR Industrial Firewall or Conduit DeviceFirewall or deep-packet-inspection device enforcing a zone boundary / conduit (IEC 62443-4-2 NDR 5.2).
NDR Managed Industrial SwitchLayer 2/3 managed switch (VLANs, port security, ring redundancy protocols).
NDR Router Cellular or WAN GatewayRouter, cellular modem or WAN gateway connecting sites or providing remote connectivity.
NDR Industrial Wireless AP or Wireless GatewayWi-Fi access point or WirelessHART / ISA100 gateway.
NDR Remote Access Gateway or Jump HostVPN concentrator, secure remote access appliance or jump server used by operators and vendors.
NDR Unidirectional Gateway or Data DiodeHardware-enforced one-way transfer device, usually with protocol replication proxies on each side.

Software applications (SAR) · 12

Stencil (as shown in TMT)What it represents
SAR HMI or Operator ApplicationHuman-machine interface used by operators to view the process and issue commands.
SAR SCADA or DCS Server ApplicationSupervisory application that polls controllers, manages alarms and sends commands.
SAR Engineering or Configuration ToolSoftware used to program controllers, download logic and firmware, and configure devices.
SAR Historian ApplicationCollects and stores time-series process data; often replicated to the enterprise.
SAR OPC UA Server or Protocol Gateway SoftwareOPC UA / OPC Classic server or protocol converter bridging field protocols to higher levels.
SAR Embedded Web Server or Device Management UIWeb-based configuration or diagnostics interface of a device or application.
SAR Edge Computing Platform or Container RuntimeEdge platform hosting containerised or third-party apps with access to OT data.
SAR Firmware or Software Update ServiceService that distributes, validates and installs firmware and software updates (local or vendor-hosted).
SAR Identity or Authentication Service AD LDAP RADIUSCentral identity provider used by OT components for user authentication and authorization.
SAR Security Monitoring or Log Collector SIEM IDS SyslogCollects security events and network traffic for detection (passive IDS, syslog, SIEM agent).
SAR Backup and Recovery ServiceBacks up and restores controller programs, configurations and host images.
SAR Asset or Device Management ApplicationManages device inventory, configuration, certificates and firmware across many devices.

Wireless Link WiFi WirelessHART ISA100 BTRadio link. Set Physical Medium to 'Wireless (RF)'.

BACnetBuilding automation protocol. BACnet/SC adds TLS.
Software Supply and Build PipelineDelivery of the product's software from the supplier's development and build environment. Carries the build pipeline and signing key threats; no other threats are generated on it.

Zones (border boundaries) · 6

Stencil (as shown in TMT)What it represents
IEC 62443 Security ZoneA zone of assets sharing common security requirements (IEC 62443-3-2). Set Purdue level and SL-T.
Safety Zone SISZone containing the safety instrumented system. Should be separate from the BPCS zone.
Industrial DMZ Level 3.5Buffer zone between enterprise and OT networks.
Component or Device BoundaryBoundary of the product itself (enclosure, firmware, hardware root of trust). Use for IEC 62443-4-2 component models.
Enterprise or IT ZoneCorporate IT network (Level 4/5).
Vendor or Cloud BoundaryInfrastructure owned by the vendor or a cloud provider.
